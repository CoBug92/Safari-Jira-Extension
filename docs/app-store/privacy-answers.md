# App Privacy Answers

Use these answers in App Store Connect App Privacy if they match the final product behavior.

## Data Collection

Does this app collect data from this app?

Answer: No, this app does not collect user or device data.

## Tracking

Does this app use data for tracking?

Answer: No.

## Encryption / Export Compliance

The app does not implement proprietary or non-standard encryption. It uses only standard operating system/browser networking to communicate with the user's Jira site.

Recommended answer if asked about encryption algorithms:

None of the algorithms mentioned above.

The project also includes `ITSAppUsesNonExemptEncryption = false` in Info.plist.
