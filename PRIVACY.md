# Privacy Policy

_Last updated: May 25, 2026_

Safari Jira Extension is a Safari Web Extension for improving Jira issue views in Safari.

## Data Collection

The extension does not collect, store, sell, or share personal data.

## Jira Data

The extension runs locally in Safari on Jira pages. It reads Jira page content and Jira issue data only to display additional fields, sorting options, and a copy-link button in the Jira interface.

Jira data is not sent to the developer or to any third-party service.

## Network Access

The extension may request Jira issue data from the Jira instance that is already open in Safari. These requests are made directly between the user's browser and their Jira site using the user's existing Jira session.

## Local Storage

The extension stores user preferences locally in Safari extension storage, such as visible fields and sorting mode. These preferences remain on the user's device.

## Clipboard

If enabled, the extension provides a button to copy a Jira issue link to the clipboard. Clipboard access is used only after the user clicks the copy button.

## Contact

For questions or support, open an issue in the project repository.
